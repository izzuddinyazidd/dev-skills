# dev-skills

Private, frozen copy of the **dev-skill** Claude Code plugin (v0.12.0), originally published as `shipwright`.

Original work by Dzafran Bustaman (https://github.com/dzaffren/claude-plugin), shared for everyone to use. Upstream has since moved on (renamed to `zuko`); this copy is pinned and does not follow it.

| Thing | Name |
|---|---|
| GitHub repo | `dev-skills` |
| Marketplace | `dev-skill-mp` |
| Plugin | `dev-skill` |

## Install

```
/plugin marketplace add izzuddinyazidd/dev-skills
/plugin install dev-skill@dev-skill-mp
```
